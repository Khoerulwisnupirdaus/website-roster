# Master Plan — Sinar Minimalis Modernization

## Objectives
Modernize Sinar Minimalis website into an architectural-grade, high-performance, mobile-first, and fully interactive product catalog with dynamic WhatsApp ordering (+62 878 6979 6938), flawless SEO, and 100% verified test coverage.

## Phases
1. **Phase 0: Survey & Discovery**
   - Dispatch 3 Explorers / Spec Miners to map existing HTML/CSS/JS codebase, inspect all image assets in `images/`, identify missing features, assess mobile responsiveness, and check existing dependencies.
   - Aggregate explorer findings into a consolidated Feature Inventory.

2. **Phase 1: Architecture, Decomposition & Test Infra Setup**
   - Formulate `PROJECT.md` with Architecture, Feature Inventory, Milestones, Interface Contracts, and Code Layout.
   - Launch E2E Testing Track (`TEST_INFRA.md`) to establish opaque-box test runner and 4 tiers of test cases (>= 11*N tests).

3. **Phase 2: Milestone Iteration Loops (Dual Track)**
   - Milestone 1: Visual Identity & Design System (Typography, palette, responsive header/footer, hero, micro-interactions).
   - Milestone 2: Complete Product Catalog & Interactivity (All roster image assets cataloged, category/material/motif filters, live search, high-res lightbox modal, dynamic WhatsApp order CTA).
   - Milestone 3: Supporting Sections & Conversions (Inspiration Gallery, Step-by-step Order Flow, Accordion FAQ, Contact form + Direct WhatsApp).
   - Milestone 4: Mobile-First Optimization, SEO, Accessibility & Performance (Zero CLS, responsive bottom nav, Open Graph / Local Purwakarta SEO, semantic tags, alt text, asset optimization).

4. **Phase 3: Final Milestone — E2E Testing & Adversarial Hardening**
   - Phase 1: Verify 100% pass rate across all E2E test tiers (Tiers 1-4).
   - Phase 2: Adversarial coverage hardening (Tier 5 with Challengers, Workers, Reviewers, and Forensic Auditor).
   - Gate verification: Clean audit, all approvals, zero errors.

5. **Phase 4: Synthesis & Sentinel Completion Handoff**
   - Document final achievements, audit reports, and test results.
   - Deliver final completion report to Sentinel (`1ea40099-2fd1-4e28-a4cf-5302f73c4bdb`).
